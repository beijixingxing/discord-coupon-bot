# Discord 公益兑换机器人

一个功能强大、部署简单、以UI为中心的 Discord 机器人，用于管理、分发和跟踪多个项目的兑换券或API密钥。

## ✨ 功能特性

- **统一的UI控制面板**: 所有核心功能都集成在一个简洁的交互式UI面板中，通过 `/公益站` 命令即可调用。
- **多项目管理**: 可同时创建和管理多个独立的兑换券项目。
- **灵活的兑换券/密钥系统**:
  - **用户端**: 通过UI面板按钮轻松完成申领、查询库存、查看个人记录等操作。
  - **管理端**:
    - 通过UI面板直观地管理项目（创建、删除、开关申领、设置冷却）。
    - 支持通过上传 `.txt` 或 `.zip` 文件批量添加兑换券。
    - 支持通过命令或粘贴文本捐赠 Gemini API Key，并自动存入数据库。
- **强大的权限与设置**:
  - 基于用户ID的管理员权限系统。
  - 可为每个项目独立**开启/关闭**申领功能。
  - 可为每个项目独立设置**申领冷却时间**。
- **用户管理与审核**:
  - 管理员可通过UI面板或命令对用户进行**全局**或**项目级**的封禁/解封。
  - 支持设置封禁时长，支持永久封禁。
- **为生产环境设计**:
  - 使用 `SQLAlchemy` 和 `aiosqlite` 进行高效、异步的数据库操作。
  - 包含自动重连逻辑和后台数据库备份任务，确保机器人稳定运行。
  - 提供 `Dockerfile` 和 `docker-compose.yml`，支持一键式容器化部署。
  - 支持通过环境变量将命令限定在**指定服务器**注册，避免对非开发服务器的干扰。

## 🚀 快速开始

### 先决条件

- [Docker](https://www.docker.com/get-started) 和 [Docker Compose](https://docs.docker.com/compose/install/)
- 一个 Discord 机器人账号并获取其 **Token**
- 准备好您的 Discord 用户 ID，用于设置机器人管理员。

### 安装与配置

1.  **克隆或下载此项目**
    ```bash
    git clone https://github.com/your-username/discord-coupon-bot.git
    cd discord-coupon-bot
    ```

2.  **创建并配置 `.env` 和 `config.yml`**
    - **环境配置**: 复制项目根目录下的 `.env.example` 文件并重命名为 `.env`。
      - 填入您的 `DISCORD_BOT_TOKEN`。
      - 填入您的 `TRUSTED_GUILD_ID` (用于开发和测试，可加快命令注册)。
      - 填入您的 `ADMIN_USER_IDS`。
    - **机器人配置**: 进入 `configs` 目录，复制 `config.example.yml` 文件并重命名为 `config.yml`。
      - 返回项目根目录。
      - 根据 `config.yml` 文件内的注释，按需调整各项功能配置。

3.  **使用 Docker Compose 启动机器人**
    在项目根目录下运行以下命令：
    ```bash
    docker-compose up -d --build
    ```
    这将会构建镜像并在后台启动机器人。

4.  **查看日志** (可选)
    如果您想确认机器人是否成功启动，可以运行：
    ```bash
    docker-compose logs -f
    ```
    当您看到 `以 YourBotName#1234 的身份登录成功` 时，表示机器人已准备就绪。

## 🤖 使用指南

机器人的所有核心功能都已集成至一个方便的 **UI控制面板**。

### 核心命令

- **`/公益站`**
  - 这是机器人的**唯一核心入口**。
  - 在任何授权频道使用此命令，机器人会发送一个仅您可见的控制面板。

### UI 控制面板功能

#### 普通用户

- **申领兑换券**: 选择一个项目，点击申领。
- **查看库存**: 查看所有项目的当前兑换券数量。
- **我的记录**: 查看您自己的申领历史记录。
- **获取帮助**: 显示机器人的使用指南。

#### 管理员

管理员面板拥有额外的高级功能：

- **项目管理**: 创建、删除、编辑项目设置（申领开关、冷却时间）。
- **用户管理**: 封禁或解封用户。
- **系统状态**: 查看机器人和服务器的实时运行状态。
- **更多操作**: 手动备份数据库、重载模块等。

### 其他命令

除核心UI面板外，还保留了一些用于特定场景的命令：

- **`/捐赠`**:
  - `file` (可选): 上传包含密钥的 `.txt` 或 `.zip` 文件。
  - `text` (可选): 直接粘贴文本格式的密钥。
  - *注意: `file` 和 `text` 参数至少需要提供一个。*
- **`/帮助`**: 显示简要的帮助信息。
- **`/状态`**: 快速查看机器人运行状态。
